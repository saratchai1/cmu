# Vendor Document Checklist

รายการเอกสารที่ควรขอจากผู้ผลิต/ตัวแทน เพื่อปิดข้อ TOR ที่หลักฐานทางเว็บหรือภาพ package ยังไม่เพียงพอ

## 1. PTV Vissim Advanced

### 4.1.7.2.1.4 — ลิขสิทธิ์ถูกต้องและตัวแทนได้รับอนุญาต
ขออย่างน้อยหนึ่งชุดจาก:
- Manufacturer Authorization Letter / Authorized Reseller Letter
- หนังสือรับรองสิทธิ์จำหน่ายจาก PTV
- License Certificate ที่ออกโดยผู้ผลิต

ข้อความที่ควรมี:
- ชื่อ product: PTV Vissim
- edition/package ที่เสนอ
- ชื่อผู้ขาย/ตัวแทน
- ยืนยันสิทธิ์จัดจำหน่ายหรือจัดหา license อย่างถูกต้อง

### 4.1.7.2.1.5.9 — Subscription ไม่น้อยกว่า 3 ปี และอย่างน้อย 1 สิทธิ์
ขอ:
- Quotation
- License Schedule
- Subscription Order / Product Schedule

ข้อความที่ควรมีแบบ exact:
- PTV Vissim Advanced
- Subscription
- Quantity: ≥ 1
- Term: ≥ 36 months / 3 years
- start/end date ถ้ามี

### 4.1.7.2.1.5.10 — อัปเดตเป็นรุ่นล่าสุดตลอดสัญญา
ขอ statement ที่ระบุ:
- software updates / upgrades included during subscription term
- entitlement to current/latest releases during contract period

---

## 2. PTV Academic License Package

### 4.1.7.2.2.5 — 25 สิทธิ์ / 3 ปี / Subscription
หลักฐานที่มีแล้ว:
- ภาพ Academic Package ระบุ **25 users / 36 months**
- PTV Academia official page ระบุ three-year access

สิ่งที่ยังควรขอเพิ่ม:
- quotation/license schedule ที่ระบุคำว่า Subscription หรือรูปแบบ license ที่เสนออย่างชัดเจน
- 25 users/seats
- 36 months หรือมากกว่า

### 4.1.7.2.2.6 — Latest-version update ตลอดระยะสัญญา
ขอ:
- subscription/maintenance terms
- statement from PTV/authorized reseller ว่า update/upgrade เป็นรุ่นล่าสุดรวมอยู่ตลอด 36 เดือน

### 4.1.7.2.2.4 — Installation / access model
แม้ evidence ด้านจำนวนผู้ใช้มีแล้ว แนะนำให้ quotation/license schedule ระบุด้วยว่าเป็น:
- named / floating / concurrent / cloud entitlement / local license ตามรูปแบบที่ PTV กำหนด
- จำนวน users/seats ที่ใช้งานได้

---

## 3. SIDRA INTERSECTION

### 4.1.7.2.3.6.5 — SIDRA Network Model + Traffic Assignment
หลักฐาน technical ที่มี:
- SIDRA ASSIGN อยู่ใน SIDRA INTERSECTION Version 11
- ทำงานร่วมกับ detailed lane-based SIDRA Network Model

สิ่งที่ต้องขอเพื่อปิด wording เชิงพาณิชย์:
- หนังสือหรือ quotation ยืนยันว่า configuration ที่เสนอมี SIDRA ASSIGN
- ยืนยันว่าไม่ต้องซื้อ license/module เพิ่มต่างหากสำหรับสิ่งที่ TOR ระบุว่า “ไม่มีค่าใช้จ่ายด้านลิขสิทธิ์เพิ่มเติม”
- หากมี module/add-on แยกจริง ต้องชี้แจงราคาและตีความกับ TOR ก่อนส่ง

### 4.1.7.2.3.7.1 — Roundabout Capacity Models ≥ 5 แบบ
หลักฐาน official ที่พบชัดเจนระบุ:
1. SIDRA Standard (HCM)
2. HCM 6
3. HCM 6 Extended
4. HCM 2010

ยังไม่พบหน้า official ที่ยืนยันรายการ **อย่างน้อย 5 แบบ** แบบตรง ๆ

ขอ:
- screenshot จาก current SIDRA User Guide / software dialog ที่แสดงรายชื่อ capacity model options ทั้งหมด
- หรือ manufacturer declaration ยืนยันจำนวน model ≥ 5 พร้อมชื่อแต่ละ model

ห้ามใช้เพียงการนับ HCM Edition 7 เป็น model ลำดับที่ 5 เพราะเอกสาร SIDRA ระบุว่า HCM Edition 7 ใช้ roundabout capacity model เดียวกับ HCM 6

### 4.1.7.2.3.5.3 — Innovative Designs
Official page พบชัด:
- DDI
- Divergabout
- CFI
- RCUT
- numerous variations / other types

แต่ในหลักฐานเว็บที่ตรวจรอบนี้ยังไม่พบข้อความตรงสำหรับทุกชื่อใน TOR โดยเฉพาะ **P-Turn**

ขอ:
- Site/Network Template list จาก User Guide เวอร์ชันที่เสนอ
- screenshot/template catalogue ที่แสดง DDI, RCUT, CFI, DLT, MUT, P-Turn, Divergabout ตาม TOR

### 4.1.7.2.3.11 — Subscription ≥ 3 ปี / ≥ 1 สิทธิ์
ขอ quotation/license schedule ที่ระบุ:
- SIDRA INTERSECTION version/package
- Subscription
- Quantity ≥ 1
- Term ≥ 36 months

### 4.1.7.2.3.12 — Update เป็นรุ่นล่าสุดตลอดสัญญา
ขอ:
- COVER/subscription terms หรือ manufacturer statement
- entitlement to software updates/upgrades throughout the contract term

---

# Suggested wording for vendor request

สามารถส่งข้อความนี้ให้ vendor ได้โดยตรง:

> Please provide official supporting documents for the proposed PTV/SIDRA licenses, including product/package name, license model, number of users/seats, subscription duration, update/upgrade entitlement throughout the contract term, and authorization status of the reseller. For SIDRA, please also confirm the SIDRA ASSIGN inclusion/licensing, the complete list of roundabout capacity models available in the proposed version, and the available innovative intersection/network templates.

---

# Final pre-submission check

ก่อนส่งชุดเอกสาร:
- [ ] ทุกข้อ **VENDOR DOC** มีเอกสารลงชื่อ/quotation/license schedule
- [ ] ทุกข้อ **PARTIAL** มี screenshot/manual page เพิ่มจนตอบ wording ครบ
- [ ] เอกสารเว็บบันทึกเป็น PDF พร้อมวันที่เข้าถึง
- [ ] ทุกหน้า evidence เขียนเลข TOR กำกับชัด
- [ ] รุ่นซอฟต์แวร์ในเอกสารตรงกับรุ่นที่เสนอจริง
- [ ] จำนวน seat/user และระยะเวลาใน quotation ตรง TOR
- [ ] ไม่ใช้ marketing screenshot แทนหลักฐานเชิงสัญญา
