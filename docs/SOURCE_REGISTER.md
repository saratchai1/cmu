## Recommended procurement evidence hierarchy

เมื่อจัดชุดเอกสารส่งจริง แนะนำเรียงน้ำหนักหลักฐานดังนี้:

1. หนังสือ/quotation/license schedule จากผู้ผลิตหรือตัวแทนที่ได้รับอนุญาต
2. Product datasheet / official User Guide / official Help
3. Official product webpage
4. ภาพ package comparison ที่มี logo/source ชัดเจน
5. เอกสารสรุป/markup ที่ทีมจัดทำเอง เช่นไฟล์ใน repo นี้

ไฟล์ใน repo นี้เป็น **index และ cross-reference** เพื่อช่วยตรวจเร็ว ไม่ควรใช้แทนเอกสารต้นฉบับจากผู้ผลิตในข้อที่เป็นเงื่อนไขเชิงสัญญา
