## License count and duration

ข้อความด้านล่างของภาพ:
- **25 users**
- **36 months**

### เลข TOR ที่ควรมาร์ค

ให้ใส่ callout ตรง “25 users / 36 months” ว่า:

**[4.1.7.2.2] + [4.1.7.2.2.5]**

เหตุผล:
- 4.1.7.2.2 ต้องการ Academic License Package รองรับ 25 ที่นั่ง
- 4.1.7.2.2.5 ต้องการระยะเวลาไม่น้อยกว่า 3 ปี และอย่างน้อย 25 สิทธิ์
- 36 months = 3 years และ 25 users ตรงกับจำนวนที่ TOR ระบุ

ให้ใช้ PTV-04 (PTV Academia) ประกอบด้วย เพราะหน้า official ระบุ Academic Package และ three-year access
